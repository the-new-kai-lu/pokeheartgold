# Pokémon HeartGold and SoulSilver

This `fakemon-starter-trio` edition gives you Voltuff, Embernewt and Sedgling from Professor Elm, and gives Silver all three original Johto starters. See [the edition guide](documentation/fakemon/STARTER_TRIO.md) for teams, testing and save-editor compatibility. Build both distinctly named ROMs with `./tools/build_starter_trio.sh`.

This is a WIP disassembly of Pokémon HeartGold and SoulSilver. For instructions on how to set up the repository, please read [INSTALL.md](INSTALL.md).

The unmodified upstream repository builds the following retail ROMs:

* [**pokeheartgold.us.nds**](https://datomatic.no-intro.org/index.php?page=show_record&s=28&n=4787) `sha1: 4fcded0e2713dc03929845de631d0932ea2b5a37`
